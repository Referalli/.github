# Contributing to Referalli SDKs and tools

Thanks for helping. Each public repository under [github.com/Referalli](https://github.com/Referalli) is generated from Referalli's main codebase. Every sync replaces the repository's contents, so a change merged here directly would be lost.

- **Bugs and feature requests:** open an issue in the repository concerned. Include the SDK version, your runtime version and a minimal reproduction. Never paste a live API key (`rk_live_…`).
- **Pull requests:** welcome as proposals. A maintainer ports the change to the main codebase and credits you in the commit, and it reaches this repository with the next sync. Your pull request is then closed with a link to the release that carries it.
- **Generated code:** API clients are generated from the OpenAPI spec. A fix to a generated file usually belongs in the generator, so describe the problem rather than editing generated files.
- **Security issues:** do not open a public issue. Follow [SECURITY.md](https://github.com/Referalli/.github/blob/main/SECURITY.md).
