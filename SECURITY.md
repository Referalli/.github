# Security policy

Please report vulnerabilities privately through GitHub: open the affected repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue, pull request or discussion.

Include what is affected (SDK and version, or the API endpoint), how to reproduce it, and the impact you expect. We acknowledge reports within three business days and keep you updated until a fix ships.

Supported versions: the latest release of each SDK and tool. Fixes are not backported to older minor versions while the SDKs are below 1.0.
